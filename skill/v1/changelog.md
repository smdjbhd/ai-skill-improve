# v1 changelog — 从手工稿里「抠」出来的第一版

> 日期：2026-11-07
> 来源：`handmade/homework1.md`（手写第 1 周）+ `handmade/reflection.md`（手写过程复盘）
> 定位：**能跑通的初版**，不是好版本。本文件记录它为什么长这样，以及我知道它哪里不行。

## 一、为什么先有 v1

手写第 1 周作业时，我实际花了约 4 小时，其中：

| 环节 | 约耗时 | 卡在哪 |
|:---|:---|:---|
| 读第 1 章做概念梳理 | 60 min | 概念之间的层级关系理不清（对称/非对称/哈希/国密怎么摆） |
| 第 2 章环境实操 | 90 min | `./config` 报错、GmSSL 版本号对不上、系统 OpenSSL 抢 PATH |
| 写 AI 总结与反思 | 50 min | 不知道该反思到什么颗粒度，容易写成"总结得不够深入" |
| 画思维导图 | 30 min | Mermaid mindmap 缩进和节点文字写法反复试错 |
| 苏格拉底对话 | 40 min | 自己跟自己对话很难编出"我真的答错"的轮次 |
| 排版与提交 | 15 min | 文件名、PDF、链接 |

复盘后发现：**耗时最多的是"结构"和"格式"，不是"知识"**。所以 v1 只做一件事——把这套结构固化成提示词，让 AI 负责组织，我负责内容真伪。

## 二、v1 做了什么（相对手工稿）

从 `handmade/homework1.md` 抽出 7 个固定章节 + 每节的写法约束，写成 `skill.md`：

1. 固定 7 个 `##` 章节、固定顺序 —— 手工稿里章节标题每次都不一样，导致最后交作业前还要重排；
2. 规定每节的**最小内容量**（反思 ≥3 条问题 + ≥2 条补充，问题 ≥2 个四段式）—— 直接对应评分点；
3. 规定**禁止编造**（命令输出、耗时、文件大小），没跑过就写 `<!-- 待补真实输出 -->` —— 手工稿里我写"大约两分钟"，自己知道是编的；
4. 规定苏格拉底对话必须包含"我答不上来 → 我反问 AI"的轮次 —— 手工稿第一版就是纯问答，读起来像百度百科；
5. 规定 Mermaid 用 `mindmap` + 根节点 `root((...))`，并给截图 —— 对应评分点「思维导图 Mermaid + 截图」。

## 三、v1 明确没做的事（留给后续版本）

| 缺口 | 现象 | 计划版本 |
|:---|:---|:---|
| 没有模板，各节长度全靠 AI 自觉 | 生成稿"学习内容"只有 4 行，"AI 总结"却有 1200 字，头重脚轻 | v2 |
| 约束不可判定 | "写深一点""要有层次"这种话 AI 无法自查 | v3 |
| 没有教材术语表 | AI 写出"国密版 RSA""SM4 分组 64 位"这类术语错误，只能在人工审阅时抓 | v4 |
| 没有自检机制 | 结构缺节、占位符残留、Mermaid 语法错，全靠人眼 | v5 |
| 只考虑"有 Linux 实验的周" | 第 3 周只有 Head First C、没有环境实验时，7 节里有 2 节没内容可写 | v6 |
| 每周都要重填输入 | 12 周要复制粘贴 12 次，配置漂移 | v7 |

## 四、本版已知问题（来自 v1 输出的真实表现）

详见 `feedback/v1-to-v2.md`，摘要：

- 生成的"学习内容"节过短，与课程 mindmap 的层级对不上；
- 苏格拉底对话只有 3 轮，且没有反问轮次（Skill 里写了要求，但 AI 没执行）；
- 思维导图节点文字混用中英文标点，渲染后换行碎；
- 反思第 4 条退化成"总结比较全面，但深度不够"，正是 Skill 自己禁止的空话。

**这四条说明：写在 Skill 里的要求，AI 不一定执行；v1 缺的是"可验证"而不是"更详细"。** 这是 v2 的出发点。
