## 这轮第一次在"别人写的稿子"上跑，立刻抓到三个真问题

1. **§2 超了 26 字**。v4 的检查是跑在 `generated.md`（1253 字）上的，人工改完以后从没重跑；把批注剥掉再数，`human-edited.md` 的 §2 是 1326 字。规则没错，错在"改完不验"。
2. **批注被当成了正文**。同一份内容，`generated.md` 1253 字、加上四条批注 1512 字，C2 直接判 FAIL。批注是审阅痕迹，必须从所有字数/别名/套话判定里排除。
3. **C11 一条规则管了两件事**。"行号越界"和"关键词不在那一行"是两种完全不同的错、修法也不同，合在一条里，FAIL 信息只能写"行号无效"，等于没说是哪种。

## 踩的坑（都记在这，v6 别再踩）

| 坑 | 现象 | 修法 |
|:---|:---|:---|
| BOM | 用 `Set-Content -Encoding UTF8` 回写后，Python 报 `SyntaxError: invalid non-printable character U+FEFF` | 只用 `io.open(..., encoding='utf-8', newline='\n')` 写；仓库里已有 3 个文件带了 BOM，已清 |
| 控制台编码 | Windows 控制台 cp936，中文 PASS/FAIL 全变乱码 | `sys.stdout.reconfigure(encoding='utf-8')` |
| 批注插错位置 | 把批注文本接在一句话后面，结果 `、AES（…）和国密的 SM4（…）` 被甩到批注行后面，C16 判 "AES 未出现" | 批注只能插在**整段之后**，不能插在句中；改动一律按行做 |
| 表格行被切断 | 把批注插在"评价"句后面，而那句在表格行里，直接把一行表格切成两半 | 批注插在整张表之后 |
| `replace` 静默失败 | 五处 `str.replace` 全部命中 0 次却不报错，字数只降了 4 | 每处 `replace` 前先 `assert old in text` |
| PowerShell here-string | `` @"…"@ `` 里反引号是转义符，`` `openssl` `` 被吃掉；`` @'…'@ `` 又会被外层引号处理弄坏 | 一次性脚本写成 `.py` 文件再跑，不塞进命令行 |
