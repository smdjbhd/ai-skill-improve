## 教材第12章（重点）

- TLS 位置：应用层与传输层之间，给 TCP 连接提供加密、身份认证、完整性。
- 协议族：记录层 + 握手层（Handshake、ChangeCipherSpec、Alert、Application Data）。
- TLS 1.2 → 1.3：1.3 简化握手（1-RTT、甚至 0-RTT）、删掉不安全套件、**强制前向保密**。
- OpenSSL 三个核心对象：`SSL_METHOD`（`TLS_client_method` / `TLS_server_method`）、
  `SSL_CTX`（配置模板：证书、私钥、套件、验证模式）、`SSL`（单个连接，绑一个套接字/BIO）。
- 服务端流程：建 CTX → 装证书链（`use_certificate_chain_file`）→ 装私钥（`use_PrivateKey_file`）→
  校验私钥与证书匹配 → 监听 → accept → 建 SSL → 绑 fd → `SSL_accept` → `SSL_read`/`SSL_write` → `SSL_shutdown`。
- 客户端流程：建 CTX → 建 TCP 连接 → 建 SSL → 绑 fd → `SSL_connect` → 收发 → `SSL_shutdown`。
- 证书验证：默认**不验证**，必须 `SSL_CTX_set_verify(ctx, SSL_VERIFY_PEER, NULL)`；
  还要 `SSL_CTX_load_verify_locations` 加载 CA；握手后用 `SSL_get_verify_result` 取错误码。
- BIO 与非阻塞：`SSL_read`/`SSL_write` 返回 ≤0 时不能直接当失败，要用 `SSL_get_error` 区分
  `WANT_READ` / `WANT_WRITE`（重试）、证书错误、连接关闭——这是实战最容易踩的坑。

## 我这周做过的（Ubuntu 虚拟机 + OpenSSL 3.3.2）

- 写了一个能连 HTTPS 的客户端，握手能成，但验证不过，错误码 **20**
  （`X509_V_ERR_UNABLE_TO_GET_ISSUER_CERT_LOCALLY`，意思是"找不到本地颁发者证书"）。
- 查清两条原因：①服务器没把中间 CA 一起发过来（链不完整）；②客户端没配 CA 库。
- 修法：`openssl s_client -connect example.com:443 -showcerts` 先看服务器到底发了哪些证书；
  再用 `SSL_CTX_load_verify_locations(ctx, NULL, "/etc/ssl/certs/")` 或
  `SSL_CTX_set_default_verify_paths()` 加载 CA。改完验证通过。
